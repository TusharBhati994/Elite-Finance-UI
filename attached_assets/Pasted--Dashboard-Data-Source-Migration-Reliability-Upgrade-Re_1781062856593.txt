# Dashboard Data Source Migration & Reliability Upgrade

Replace the current Alpha Vantage integration completely with Yahoo Finance (yfinance).

## Primary Goal

Eliminate Alpha Vantage rate-limit issues and ensure the dashboard loads reliably on first launch without showing "No data returned" errors.

---

## 1. Remove Alpha Vantage Completely

Remove all Alpha Vantage-related code, including:

* API keys
* API endpoints
* Rate-limit handling
* Retry logic specific to Alpha Vantage
* Any references to the 25 requests/day limitation
* Any user-facing messages mentioning Alpha Vantage

The dashboard should no longer depend on Alpha Vantage in any way.

---

## 2. Use Yahoo Finance (yfinance)

Use:

```python
import yfinance as yf
```

Create a dedicated market data service layer.

Example:

```python
ticker = yf.Ticker(symbol)
data = ticker.history(period=period, interval=interval)
```

---

Support the following intervals:

* 1d

Support the following periods:

* 1d
* 5d

## 4. Implement Intelligent Caching

If using Streamlit:

```python
@st.cache_data(ttl=60)

    ...
```

## 5. Add Robust Retry Logic

Implement automatic retries:

```python
for attempt in range(3):
    try:
        ...
        break
    except Exception:
        time.sleep(2)
```

Requirements:

* Retry up to 3 times
* Wait between retries
* Log failures
* Prevent crashes

---

## 6. Improve Error Handling

Never display:

"No data returned"

Never display raw exceptions to users.

Instead display friendly messages such as:

* "Loading market data..."
* "Unable to fetch market data. Retrying..."
* "Market data temporarily unavailable."
* "Please try again in a few moments."

If the returned dataframe is empty:

```python
if data.empty:
    handle_gracefully()
```

The dashboard must never crash because of missing market data.

## 12. Live Data Consideration

If the dashboard is intended to display live candlesticks updating every few seconds, evaluate whether yfinance is sufficient.

Important:

* yfinance is excellent for analysis dashboards, portfolio tracking, research tools, and quant projects.
* yfinance is NOT true tick-by-tick real-time market data.
* If the dashboard requires genuine live streaming candles or second-by-second updates, migrate the live data layer to a WebSocket-based market data provider or broker API.

Examples:

* Broker WebSocket APIs
* Exchange WebSocket feeds
* Streaming market data providers

For standard portfolio, quant research, educational, and internship projects, yfinance is acceptable and preferred due to simplicity and reliability.
